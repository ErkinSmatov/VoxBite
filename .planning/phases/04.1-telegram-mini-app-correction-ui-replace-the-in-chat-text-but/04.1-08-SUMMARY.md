# Phase 04.1 Plan 08: Mini App Shell — Types, Telegram Bridge, API Client, Copy, Styles, Screen Summary

**Built the Mini App's frame: a hand-kept `DraftResponse` type mirror, an `initData`-authenticated fetch client with a discriminated result type, every Russian string in one module (with the expired/not-yours IDOR-privacy string kept as a single shared constant), a `--tg-theme-*`-driven stylesheet, and the mounted screen with loading/error/ready states rendering read-only placeholder rows.**

## Accomplishments
- `mini-app/src/types.ts` mirrors the exact `DraftResponse` interface recorded in 04.1-03-SUMMARY.md, plus `DraftComponent`/`FdcCandidate`/`NutrientTotal` from `src/application/types.ts`/`src/domain/fdc-matching/types.ts`/`src/domain/nutrition/calculate-total.ts`, plus the full `ApiErrorCode` union every endpoint can return.
- `mini-app/src/lib/telegram.ts` wraps `window.Telegram.WebApp`: `getRawInitData()` (raw signed string only — no function in this module ever returns a user id), `getDraftIdFromUrl()` (positive-integer-only), `telegramReady()` and `closeApp()`, both guarded so the module works outside a real WebView.
- `mini-app/src/lib/api-client.ts`'s `apiGet`/`apiPost` attach `Authorization: tma <initData>` and return a discriminated `ApiResult<T>` distinguishing a successful payload, a structured API failure (status + error code, optional `blockedComponent`), and a network/transport failure — never throws.
- `mini-app/src/copy.ts` carries every string from 04.1-UI-SPEC.md's Copywriting Contract table; the nine strings the plan required to verify byte-for-byte against `correction-copy.ts` (`btnConfirm`, `btnAdd`, `btnRemove`, `btnDelete`, `noData`, `headerLevel1`, `deletePrompt`, `gramsRejected`, `expired`) were checked programmatically — all MATCH. `expired`/`notYours` reference one `EXPIRED_OR_NOT_YOURS` constant.
- `mini-app/src/styles.css` defines the UI-SPEC's spacing/typography/color tokens as CSS custom properties over `--tg-theme-*`, with static fallbacks for local dev; a `.tap-target` (44px floor), `.sticky-header`/`.sticky-footer` (safe-area-inset padding). No parallel dark-mode media query.
- `mini-app/src/main.tsx` calls `telegramReady()` before `createRoot(...).render(<App/>)`, no StrictMode wrapper. `App.tsx` reads `draftId` from the URL, does exactly one `apiGet` call on mount into a `loading | error | ready` state machine, maps 401/403/404/410 to `copy.expired` and network/5xx to `copy.loadFailed` + retry, and renders one placeholder row per component (name, grams, chosen candidate description or `copy.noMatch`) — zero nutrient arithmetic in any `.tsx` file.
