<objective>
Delete Phase 4's chat-native correction UI and every trace of the `awaiting_input` mechanism from
the code, now that the Mini App provides the same capabilities (D-04).

Purpose: two parallel ways to correct a draft means two places for the same bug — the exact
pattern Phase 4's own D-06 rejected. More concretely, the text-input gate being removed here is
the thing that shipped a live defect twice (04-UAT.md rounds 3-4): a typed correction on a
reopened saved entry leaking into the paid decomposition pipeline and creating a duplicate diary
row. It is not being fixed a third time, it is being removed.
Output: five deleted modules, a simplified text handler, and an application layer with no
awaiting-input concept left. The database column itself is dropped in plan 12.
</objective>
