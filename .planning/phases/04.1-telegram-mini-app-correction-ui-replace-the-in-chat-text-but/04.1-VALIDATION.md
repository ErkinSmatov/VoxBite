## Sampling Rate

- **After every task commit:** Run the quick run command, scoped to the file(s) touched.
- **After every plan wave:** Run `npm test` (full suite).
- **Before `/gsd:verify-work`:** Full suite must be green, PLUS a manual owner-executed checklist for the actual Mini App UI inside a real Telegram WebView (no way to script a real Telegram WebView session — same precedent as Phase 4).
- **Max feedback latency:** ~20 seconds.
