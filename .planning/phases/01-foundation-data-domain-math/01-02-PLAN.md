    1. Open https://supabase.com and click "Start your project". Sign in with
       GitHub or with an email address.
    2. In the dashboard click "New project".
       - Organization: pick the existing one or create one (any name).
       - Name: `voxbite`
       - Database Password: click "Generate a password" and IMMEDIATELY copy it
         into a password manager or a note. Supabase shows it once. If it is
         lost, it can be reset later at Project Settings -> Database -> "Reset
         database password", but every stored connection string must then be
         updated.
       - Region: pick the geographically closest one — for Kazakhstan/Central
         Asia that is typically `Central EU (Frankfurt)` / `eu-central-1`.
       - Plan: Free.
       Click "Create new project" and wait ~2 minutes while it provisions.
    3. Enable the vector extension: left sidebar -> "Database" -> "Extensions".
       Search for `vector`. Toggle ON the extension named exactly `vector`
       (its description mentions "vector data type and ivfflat and hnsw access
       methods"). Accept the default schema Supabase offers. If the toggle is
       already on, nothing to do.
    4. Get the connection string: click the "Connect" button in the top bar (on
       some dashboard versions: Project Settings -> Database -> "Connection
       string"). A tabbed panel appears. Choose the tab labelled
       **"Session pooler"**. Do NOT use "Direct connection" and do NOT use
       "Transaction pooler".
       - Why: "Direct connection" only works from networks that have IPv6, which
         most home internet providers do not guarantee. "Transaction pooler"
         (port 6543) does not support prepared statements, which the database
         migration tool needs. "Session pooler" (port 5432) works from any
         normal network and supports migrations.
       - The correct string looks like
         `postgresql://postgres.<project-ref>:[YOUR-PASSWORD]@aws-0-<region>.pooler.supabase.com:5432/postgres`
         — note the host ends in `pooler.supabase.com` and the port is `5432`.
    5. In the project folder run `cp .env.example .env` (creates the private
       local settings file; it is already git-ignored so real passwords in it
       can never be committed).
    6. Open `.env` and set `DATABASE_URL` to the copied string with two edits:
       replace `[YOUR-PASSWORD]` with the password from step 2, and make sure the
       string ends with `?sslmode=require` (add it if the copied string does not
       already have query parameters). Keep the value on one line, no quotes,
       no spaces around `=`.
    7. Note for later: on the free tier Supabase pauses a project after ~7 days
       with no activity. If a later command suddenly cannot connect, open the
       dashboard and click "Restore"/"Resume project".

    owner. If it fails, use the remediation line the script prints (wrong
    password, wrong host, missing sslmode, extension not enabled) and iterate —

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser dashboards -> local `.env` | Long-lived credentials are transcribed by hand here |
| Local `.env` -> git remote | Must never be crossed |
| Local process -> OpenAI billing account | Every call spends real money |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-02 | Information Disclosure | `.env` (Supabase password, OpenAI key) | mitigate | `.env` git-ignored by Plan 01 before any secret exists; acceptance criteria assert no `sk-proj-` string exists outside `.env`; key revocation path documented in the task action |
| T-01-03 | Denial of Service (owner's budget) | OpenAI account | mitigate | Hard spend limit $5 + notification threshold $2 + auto-recharge OFF + capped prepaid balance; downstream batch size capped at 100 texts/call and the loader is idempotent (Plans 06/07) |
| T-01-07 | Spoofing / credential theft | Supabase database password | mitigate | Password stored only in a password manager and `.env`; reset path documented; Session Pooler endpoint is TLS-only via `sslmode=require` |
| T-01-08 | Denial of Service (availability) | Supabase free tier auto-pause | accept | Free tier pauses after ~7 days idle; documented in the task action with the "Restore project" remedy — acceptable for a closed beta |
</threat_model>
