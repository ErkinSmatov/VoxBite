`fdc_foods` with a pgvector column + HNSW index), generate versioned SQL
migrations for it, apply them to the real Supabase database created in Plan 02,

without it — the FDC indexing pipeline writes into `fdc_foods`, and the vector
similarity search that MATCH-01 depends on is impossible without the
`vector(1536)` column and its HNSW index physically existing in Postgres.

matches it, and `npm run verify-schema` reporting green.
