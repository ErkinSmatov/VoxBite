<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `callback_query.data` -> answers object | Client-controlled; a modified client can send values never rendered as buttons |
| Free-text message -> numeric profile fields | Arbitrary user input flowing into a calorie formula and a checked database column |
| Conversation replay -> `users` write | The plugin re-executes the function body after every update; a naive write runs more than once |
| Profile values -> logs | Sex, age and weight are personal, health-adjacent data |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-16 | Tampering (ASVS V5) | Callback handling in `onboarding.ts` | mitigate | Every callback value goes through `decodeOption`/`decodeRate` and an `undefined` result re-asks the question instead of writing; the keyboard/decoder round-trip is asserted by Task 1's tests, so no renderable value is undecodable and no decodable value is unrenderable |
| T-02-17 | Tampering (ONBOARD-02 product-safety cap) | Rate selection end-to-end | mitigate | `buildRateKeyboard` derives from `RATE_PRESETS_KG_PER_MONTH` with no second literal source; `decodeRate` refuses non-presets; `calculateTargetCalories` clamps; `users_desired_rate_check` rejects at the database; `saveOnboardedUser` persists the clamped `targets.rateKgPerMonth` rather than the request |
| T-02-18 | Repudiation / data integrity (replay) | `users` write during conversation replay | mitigate | The write happens only inside `conversation.external()` and is an `onConflictDoUpdate` on `telegramId`, so a replay cannot create a duplicate or a partial row; an automated check fails the task if a direct `db.*` call appears in the conversation |
| T-02-19 | Safety / regulatory (ONBOARD-06) | Confirmation screen | mitigate | The disclaimer is concatenated into the same message as the numbers by `targetsWithDisclaimerMessage`, whose content is unit-tested in Plan 02; the conversation is forbidden from composing its own targets message |
| T-02-20 | Information Disclosure | Logging of profile answers | mitigate | Neither `save-user.ts` nor `onboarding.ts` contains any `console.*` referencing answers; automated checks enforce this in `save-user.ts` |
</threat_model>
