Codec (04-RESEARCH.md Pattern 2 — `callback_data` is capped at 64 BYTES, and Cyrillic burns
them fast, so encode integers and short ASCII tokens only, never a description or a component
name):
- `export const CRC_PREFIX = 'crc';`
- `export type CrcAction = 'sel' | 'cand' | 'gm' | 'gp' | 'gtype' | 'rm' | 'back' | 'add' |
  'confirm' | 'cancel' | 'edit' | 'del' | 'delyes' | 'delno';` — one token per button in D-01,
  D-05, D-08 and D-12. Keep them short; document each with the decision it serves.
- `export interface CrcCallback { draftId: number; action: CrcAction; index?: number }`
- `export function encodeCrc(cb: CrcCallback): string` — `crc:<draftId>:<action>` plus
  `:<index>` when an index is present. Throw on a non-integer draftId/index (a builder bug).
- `export const CRC_PATTERN: RegExp` — a STRICT anchored pattern
  (`^crc:(\d+):([a-z]+)(?::(\d+))?$`) exported so plan 09's `bot.callbackQuery(...)`
  registration and this module can never drift. A loose `split(':')` parse is forbidden
  (04-RESEARCH.md Security Domain V5).
- `export function parseCrc(data: string): CrcCallback | null` — matches `CRC_PATTERN`, then
  validates the action against the `CrcAction` union and bounds the parsed integers
  (`Number.isSafeInteger`, non-negative). Returns `null` — never throws, never a partial object
  — for anything unexpected, so a malformed or hand-crafted callback is simply ignored.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| FDC description text (external USDA data) → Telegram message body | Untrusted text rendered to the user |
| `callback_data` string (user-controllable on replay) → handler dispatch | Parsed into an id and an action |
| Nutrient nulls → displayed numbers | A rendering shortcut can manufacture a false health claim |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-06 | Spoofing / Tampering | `parseCrc` | mitigate | Anchored `CRC_PATTERN` plus an action-union check and `Number.isSafeInteger` bounds; loose `split(':')` parsing is forbidden by an acceptance-criteria grep; malformed input returns `null` and is ignored |
| T-04-25 | Tampering (rendering) | FDC descriptions in the card | mitigate | Sent as plain text with no `parse_mode` (Phase 3 invariant preserved); a description containing `_` or `*` cannot break rendering or inject markup |
| T-04-26 | Tampering (data integrity) | totals rendering | mitigate | `formatTotalsBlock` is the only Russian-text renderer of a `NutrientTotal`, and it calls `calculateTotal`; a null-everywhere nutrient renders `нет данных`, a partially-known one renders a lower bound naming the missing count — never 0 (D-09, CALC-02) |
| T-04-27 | Denial of Service | oversized `callback_data` | mitigate | Every emitted `callback_data` is asserted ≤ 64 UTF-8 bytes; descriptions and component names are never encoded into it |
| T-04-19 | Information Disclosure | card content | accept | The card shows the user their own transcript-derived component names and public USDA descriptions; nothing cross-user and no internal ids beyond the draft id already in `callback_data` |
</threat_model>
